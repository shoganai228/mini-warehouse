Выполнил тестовое задание по разработке веб-программы «Мини-склад»[cite: 1]. Исходный код и инструкция по запуску доступны в репозитории:

https://github.com/shoganai228/mini-warehouse[cite: 3]

Что сделано и какие решения приняты:
Архитектура и безопасность: В качестве стека выбрана связка Python + Django[cite: 1]. Интерфейс построен на сервере (Django Templates + Bootstrap 5) с поддержкой тёмной темы и адаптивности под мобильные устройства[cite: 1, 2].
Контроль прав на сервере: Все ограничений ролей (Руководитель, Кладовщик, Менеджер) зафиксированы строго на бэкенде[cite: 1]. Кладовщик не получает данные о ценах даже при прямых запросах в обход UI[cite: 1].
Бизнес-логика остатков: Реализована валидация отрицательных остатков[cite: 2]. Отмена прихода блокируется, если товар из него уже выдан на объекты и операция приведет к минусовому балансу[cite: 2].
Точность денег и надежность: Все денежные поля используют Decimal (без ошибок округления плавающей точки)[cite: 2]. Итоги считаются отдельно по каждому типу валют[cite: 2]. Добавлена защита от повторной отправки формы при двойном клике[cite: 2].
Каталог товаров: Управление справочником вынесено в административную панель Django[cite: 1].
