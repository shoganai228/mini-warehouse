> 
> **Что сделано и какие решения приняты:**
> 1. **Архитектура и безопасность:** В качестве стека выбрана связка Python + Django. Интерфейс построен на сервере (Django Templates + Bootstrap 5) с поддержкой тёмной темы и адаптивности под мобильные устройства.
> 2. **Контроль прав на сервере:** Все ограничения ролей (Руководитель, Кладовщик, Менеджер) зафиксированы строго на бэкенде. Кладовщик не получает данные о ценах даже при прямых запросах в обход UI.
> 3. **Бизнес-логика остатков:** Реализована валидация отрицательных остатков. Отмена прихода блокируется, если товар из него уже выдан на объекты и операция приведет к минусовому балансу.
> 4. **Точность денег и надежность:** Все денежные поля используют `Decimal` (без ошибок округления плавающей точки). Итоги считаются отдельно по каждому типу валют. Добавлена защита от повторной отправки формы при двойном клике.
> 5. **Каталог товаров:** Управление справочником вынесено в административную панель Django.
